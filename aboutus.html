The project

ISM 6225 · Assignment 1

A small visual archive, built to be explored.

This photography portfolio was created for ISM 6225’s “Look and Feel” assignment. Its purpose is to make a static collection of themed data useful and enjoyable to explore by presenting photographs and making their details searchable, manageable, and visible through simple analytics.

The site is built with semantic HTML, responsive CSS, and plain JavaScript. The collection is sample data; the management page demonstrates create, read, update, and delete interactions using this browser’s local storage. Chart.js turns the same collection into category, year, and location visualizations.
